# T008 Operator Plan

## Goal

Complete only T008: render accessible interactive charts and concise,
deterministic summaries grounded entirely in validated query results.

## Boundaries

- Work only under `src`.
- Reuse `AnalysisResult`, `AnalysisRow`, and `ChartSelection` from
  `src/lib/deterministic-analysis.ts`.
- Keep tables accessible and available alongside charts.
- Do not invent claims that are absent from the query result.
- Do not restore, reset, or overwrite unrelated working-tree changes.
- Use native React, HTML, CSS, and SVG only. Do not add Recharts, Chart.js,
  scripts, CDNs, package changes, or dependencies.
- Do not push or deploy.

## Implementation Shape

1. Add a small pure module under `src/lib` for deterministic result summaries
   and chart-series derivation. Summary text may mention only the row count,
   selected chart fields/type, and extrema calculated from `result.rows`.
2. Add a focused result-view component under `src/components`. It must:
   - always render the existing accessible result table;
   - render no chart when `result.chart.type` is `table`;
   - render a responsive native SVG for `bar`, `line`, and `scatter`;
   - expose an accessible chart name and per-point values through SVG
     `title`, labels, or equivalent focusable markup;
   - use stable `viewBox` dimensions so content cannot shift the layout.
3. Add component-local CSS in a new file. Use visible focus and hover states,
   restrained colors, and responsive constraints.
4. Change `src/App.tsx` only at two exact integration points:
   - add one import for the result-view component;
   - replace the current `localAi.result` table block with that component.
5. Add focused tests for the pure summary/series logic and result component.
   Do not rewrite the existing App tests.

Use full `content` only for new files. For existing files, use one edit per
path with compact exact `replacements`; anchors must be non-empty and unique.

## Validation

- Chart selection follows the validated plan.
- Summaries are reproducible from result values.
- Tests cover bar/line/scatter series, table-only fallback, accessible table,
  accessible chart naming, and grounded summary text.
- `npm run typecheck`, `npm run lint`, `npm run test`, and `npm run build` pass.
